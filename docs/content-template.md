# Metro Line Markdown Template

Use this structure for both English and Chinese files.

```markdown
# <Line Name>

## Quick Intro
<2 to 4 short sentences.>

## Story Time
<A short story-style section that explains the background of this line.>

<What problem did the city have before this line?>

<Why did people want to build it?>

<What was exciting or important about the construction or opening?>

<Why does this line still matter today?>

## Time Story
- <Year>: <What happened>
- <Year>: <What happened>
- <Year>: <What happened>

<1 short paragraph explaining why this line matters.>

## Route Snapshot
- Start area: <...>
- End area: <...>
- Route role: <...>
- Transfer value: <...>

## Important Stations for Kids
### 1) <Station Name>
<Child-friendly reason this station matters.>

### 2) <Station Name>
<Child-friendly reason this station matters.>

### 3) <Station Name>
<Child-friendly reason this station matters.>

## Fun Facts
- <Verified fact 1>
- <Verified fact 2>
- <Verified fact 3>

## Word Helper
- <Term>: <Simple child-friendly explanation>
- <Term>: <Simple child-friendly explanation>
- <Term>: <Simple child-friendly explanation>

## Memory Check
1. <Question 1>
2. <Question 2>
3. <Question 3>

## Sources
- <Source name>: <URL>
- <Source name>: <URL>
- <Source name>: <URL>
```

## Writing Pattern
- Use short sentences.
- Keep one main idea per sentence.
- Keep paragraphs short.
- Explain difficult terms as soon as they appear.
- Explain important terms briefly inline when they first appear.
- Prefer vivid but factual phrasing.
- Avoid overloaded number-heavy lines.
- Use narrative voice in `Story Time`, but keep all major claims source-backed.
