# 🌉 广佛线 — 城际桥梁！

> 🌉 **趣味小知识：** 广佛线连接**两座不同的城市**——广州（广）和佛山（佛）！"广佛"就是两座城市名字的头字拼在一起：广+佛=广佛！

## 🚉 基本信息
| | |
|---|---|
| 🎨 颜色 | 黄绿色 |
| 🔢 站数 | **32座车站** |
| 🌆 特别 | 一程列车，穿越**两座城市**！ |

## ⭐ 著名车站
- 🔄 **西朗站** — 广州换乘枢纽（同时连接1号线和7号线）！
- 🛣️ **魁奇路站** — 佛山的重要站点！
- 🏙️ **佛山站** — 佛山市中心！

## 🌟 特别之处
广州和佛山的距离越来越近，几乎要合并成一座超级大城市！广佛线每天帮助数百万市民在两座城市之间通勤——没有它，道路会变得无比拥堵。两座城市，一条地铁，无数幸福的乘客！🎉

## 🎈 有趣小故事
佛山以**功夫**举世闻名！🥋 传奇人物李小龙的祖籍就在佛山，同样家喻户晓的黄飞鸿也是佛山人。坐广佛线去佛山，就像踏入功夫大师的故乡！
