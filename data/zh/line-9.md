# 🌱 9号线 — 花都小探险！

> 🌿 **趣味小知识：** 9号线一路通到**花都区**——广州北部一个以鲜花闻名的美丽地方！花都还举办著名的中国（广州）国际园林博览会！🌺

## 🚉 基本信息
| | |
|---|---|
| 🎨 颜色 | 浅绿色 |
| 🔢 站数 | **10座车站** |
| 📏 方向 | 从南部进入花都 |

## ⭐ 著名车站
- 🦅 **飞鹅岭站** — "飞翔之鹰岭"——多酷的名字！
- 🏙️ **花都广场站** — 花都区的中心！
- 🌸 **新华站** — 附近有美丽的花园小镇！

## 🌟 特别之处
花都是广东省著名的**"花城"** 🌸！这里有大型花卉市场和园圃，每年都有来自各地的人前来欣赏美丽的花海。9号线就是你通往花城的专列！

## 🎈 有趣小故事
"花都"的意思就是**"鲜花之都"**！🌷 想象一下，住在一个用鲜花命名的地方——每天都像春天一样！

```
飞鹅岭 → … → 花都广场 → 新华
```
