# 🟡 1号线 — 开路先锋！

> 🏆 **趣味小知识：** 1号线是广州地铁的**第一条线路**，早在 **1997年** 就开通了！它是所有广州地铁线路的"爷爷"！

## 🚉 基本信息
| | |
|---|---|
| 🎨 颜色 | 黄色 |
| 🔢 站数 | **16座车站** |
| 📏 方向 | 东西向穿越广州中心 |

## ⭐ 著名车站
- 🏁 **西朗站** — 西边的起点站！
- 🚄 **广州东站** — 可以换乘去其他城市的快速列车！
- 🏟️ **天河体育中心站** — 旁边就是巨大的体育场馆！

## 🌟 特别之处
1号线穿越广州市的**心脏地带**！正是因为它，才有了今天整个地铁网络。所有其他线路都是在1号线之后才建起来的。1号线带路，大家都跟上！🎉

## 🎈 有趣小故事
1号线刚开通时，只有**几列列车**运行。现在，列车每隔几分钟就来一班！想象一下，等很长时间才能坐到地铁——现在完全不一样啦！😄

## 🗺️ 线路走向
```
西朗 → … → 公园前 → … → 广州东站
```
穿越广州中心，把西边和东边紧紧连在一起！
