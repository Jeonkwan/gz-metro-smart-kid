# ✨ 11号线 — 环形线！

> ⭕ **趣味小知识：** 11号线是一条**环形线**——它绕着市中心画了一个大圆圈，就像一个给列车玩的巨型呼啦圈！��

## 🚉 基本信息
| | |
|---|---|
| 🎨 颜色 | 橙色/金色 |
| 🔢 站数 | **8座车站**（环形段） |
| 📏 方向 | 环形循环 |

## ⭐ 著名车站
- 🚂 **广州火车站** — 气派的老火车站，1974年开业！
- 🚌 **天河客运站** — 四通八达的长途客运枢纽！
- ⛪ **赤岗站** — 老城区东部的历史地带！

## 🌟 特别之处
环形线超级特别——因为你可以**绕圈坐**！没有终点站，坐过了站也没关系，继续绕一圈就回来了。就像城市里的旋转木马！🎠

## 🎈 有趣小故事
广州火车站（不是南站！）建于1974年，造型如同宏伟的宫殿🏰，曾是中国最繁忙的火车站之一！现在11号线把它连入现代地铁网络，继续发光发热。

## 🗺️ 线路走向
```
🔄 → 广州火车站 → 天河客运站 → 赤岗 → 🔄
```
绕啊绕——广州地铁的金色光环！
