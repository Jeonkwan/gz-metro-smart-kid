# 🌸 海珠有轨电车 — 花园观光车！

> 🌸 **趣味小知识：** 海珠有轨电车是一辆穿梭于海珠区绿道公园的**悠闲小电车**——你是在花园里乘车！🌿🌺

## 🚉 基本信息
| | |
|---|---|
| 🎨 颜色 | 绿色 |
| 🔢 站数 | **7座车站** |
| 🚋 类型 | 轻轨有轨电车（地面运行！） |
| 🌿 特别 | 穿越**绿道公园**行驶！ |

## ⭐ 著名车站
- 🔄 **万胜围站** — 换乘4号线和8号线！
- 🌺 **瑞宝东站** — 海珠腹地！
- 🌿 **南洲站** — 南部绿意！

## 🌟 特别之处
与大多数在地下行驶的地铁不同，海珠有轨电车在美丽的绿道公园走廊里**地面运行**！🌳 绿道旁有人慢跑和骑行。这是一段悠然惬意的旅途，非常适合欣赏风景！

## 🎈 有趣小故事
海珠有轨电车线路是沿着原来的**老工厂铁路轨道**建造的！🏭 人们把老工业区改造成美丽的绿色公园，配上有轨电车——把旧的变成美好又实用的新事物。这叫做**升级再造**！♻️✨
