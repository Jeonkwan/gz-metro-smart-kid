# 🌲 12号线 — 南沙航行者！

> 🚢 **趣味小知识：** 12号线一路通到**南沙客运港**——在这里可以登上轮渡，飘洋过海前往澳门或香港！🌊

## 🚉 基本信息
| | |
|---|---|
| 🎨 颜色 | 橄榄绿 |
| 🔢 站数 | **20座车站** |
| 📏 方向 | 由北向南通往南沙 |

## ⭐ 著名车站
- 🔄 **嘉禾望岗站** — 北部换乘枢纽！
- 🏰 **龙归城站** — "龙归之城"——多有趣的名字！🐢🐉
- 🚢 **南沙客运港站** — 从这里出发，海上冒险开始！

## 🌟 特别之处
在**南沙客运港**，你可以坐高速船约一小时到达**澳门**，也可以前往**香港**！想象一下：地铁+渡轮=国际大冒险！🌏✨

## 🎈 有趣小故事
**龙归城**（龙归城）意思是"龙回城"🐉！听起来就像一部史诗冒险电影的片名。也许南沙某处真的藏着龙……（开玩笑啦！😄）
