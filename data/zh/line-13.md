# 🌾 13号线 — 东部先锋！

> 🌾 **趣味小知识：** 13号线延伸至**增城**——广州最东端，那里以荔枝出名！🍈 增城荔枝是全世界最美味的！

## 🚉 基本信息
| | |
|---|---|
| 🎨 颜色 | 黄绿色 |
| 🔢 站数 | **14座车站** |
| 📏 方向 | 从西向东通往增城 |

## ⭐ 著名车站
- 🎆 **鱼珠站** — 靠近著名的广交会展馆——全球最大的贸易展会！
- 🌊 **新沙站** — "新沙"——就在河边！
- 💧 **水西站** — "水西"——多诗意的名字！

## 🌟 特别之处
每年，鱼珠站附近的**广交会（中国进出口商品交易会）**吸引来自**200多个国家**的商家！这是全世界最重要的贸易盛会之一，就在广州！🌍🤝

## 🎈 有趣小故事
增城是**"荔枝之乡"** 🍈！大诗人苏东坡一千多年前曾写诗赞美岭南荔枝。增城有些荔枝树已经超过400年树龄！想象一棵比一些国家还老的树！
