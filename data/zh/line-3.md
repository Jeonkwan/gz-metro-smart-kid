# 🟠 3号线 — 最长的冒险旅途！

> ✈️ **趣味小知识：** 3号线是广州**最长的地铁线路**！它甚至能一路通到**机场**——坐地铁就能去赶飞机！

## 🚉 基本信息
| | |
|---|---|
| 🎨 颜色 | 橙色 |
| 🔢 站数 | **36座车站**（含支线！） |
| 📏 方向 | 南北走向 + 机场支线 |

## ⭐ 著名车站
- 🚌 **天河客运站** — 长途客车四通八达！
- 🚄 **广州东站** — 换乘快速列车！
- 🏃 **体育西路站** — 运动购物两不误！
- ✈️ **机场北/机场南站** — 飞向远方！一路顺风！🛫

## 🌟 特别之处
3号线有一条**神奇支线**——列车在某个节点会"分叉"，一部分开往机场，另一部分开往番禺南！就像一列能选择两条不同道路的火车！🛤️🛤️

## 🎈 有趣小故事
机场站有 **T1（一号航站楼）** 和 **T2（二号航站楼）** 两个站。每年数以百万计的旅客在广州白云国际机场起落，很多人都乘3号线抵达机场！🌍

## 🗺️ 线路走向
```
番禺广场（南）→ … → 体育西路 → … → 机场北 ✈️
                           ↘ 支线 → 天河客运站
```
两个终点，一条超棒的线路！
